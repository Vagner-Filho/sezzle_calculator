# Frontend spec (scope: `front/`)

## UI: Definition of UI rules to apply

## The UI must be accessible and avoid uneccessary element movement (FR)
- Use WAI-ARIA attributes and semantic HTML properly, such as in the result placeholder and operation buttons.
- Input field b must not disappear when it is not needed, only disabled.
- When disabled, input field b must visually indicate that it is not operable.

## Non-functional requirements (NFR)
- The UI must use a modern style by mixing light touches of neumorphism and opacity/transparent/glassy effects of liquid glass while maintaining contrast.

## Acceptance criteria
- Functional testing by user: Approved.
